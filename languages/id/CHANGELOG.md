# Bahasa Indonesia (Indonesian): changelog

## 1.0 (unreleased)

First version: 7,958 of the game's 9,093 texts (the other 1,135 are the same in every official language: names, numbers, abbreviations).

- Draft by 8 professional-translator agents working in parallel batches, with the English text, the official French, German, Italian and Spanish texts as context and the glossary (`glossary.md`), which follows the terms Konami uses in eFootball in Indonesian.
- Repeated texts unified (the same English text with the same official translations gets one translation) and the unified terms fixed in the glossary.
- Help texts checked against the menus: every option they quote in brackets is the menu's own label.
- Checked with `pes6tr.py check`: same control codes, button icons and `%` formats as the original.
- `letras.py`: every letter is in the PES6 HD Text font.
- Tested in the lab (2026-11-21).
